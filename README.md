# Earth Observation Smear Simulation

Modelo de simulación de telemetría de imágenes para cargas útiles de observación de la Tierra (arquitecturas Push-Broom).

Este proyecto simula la degradación de resolución espacial (smear) que sufren las imágenes satelitales debido a la alta velocidad orbital terrestre baja (LEO) y al tiempo de integración del sensor CMOS/CCD. Incluye algoritmos de deconvolución (Filtro de Wiener) para procesar digitalmente la imagen y recuperar la nitidez del terreno costero o urbano capturado.
